Сервер запускается. Для запуска потока с серверной частью необходимо нажать на кнопку "Запустить сервер".
Сервер получает подключение и после авторизации добавляет клиента в таблице Клинетов.
Для начала отправки пакетов от подключенного клиента, необходимо вызвать контекстное меню в таблице Клинетов и
выбрать из активных пунктов меню "Получать только логи вариннг", "Получать любые пакеты" или "Остановить пакеты".
