СЕРВЕР
Сервер запускается. Для запуска потока с серверной частью необходимо нажать на кнопку "Запустить сервер".
Сервер получает подключение и после авторизации добавляет клиента в таблице Клинетов.
Для начала отправки пакетов от подключенного клиента, необходимо вызвать контекстное меню и
выбрать "Получать только логи вариннг" или "Получать любые пакеты".

КЛИЕНТ
Клиент запускается. Выводится название клиента. Ожидает подключения и отправляет авторизацию.
Ожидает команды на отправку определенных пакетов.



Папка build содержит exe файлы для запуска клиента и сервера.
